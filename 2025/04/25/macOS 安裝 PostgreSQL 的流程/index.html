6. 常見問題與解決方法

問題 1：psql: 錯誤: role "postgres" does not exist

解決方法：

  • 使用 createuser -s postgres 建立 postgres 使用者。

問題 2：啟動 PostgreSQL 時出現 Bootstrap failed: 5: Input/output error

解決方法：

  • 刪除舊的啟動檔案並重新啟動服務：

7. 注意事項

  1. 版本管理：安裝多個版本的 PostgreSQL 時，需確認環境變數是否正確指向目標版本。
  2. 資料庫初始化：若安裝後無法啟動，可能需要手動執行 initdb 初始化資料庫。
  3. 權限問題：確保使用者擁有足夠的權限來操作資料庫。
  4. 服務管理：使用 brew services 管理 PostgreSQL 的啟動與停止。
